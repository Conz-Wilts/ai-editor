# skills

# Folders

* [clips](clips/) - Turns one long video or podcast (a local file or a YouTube link) into the best 3-5 short vertical clips, each cut and styled in the user's profile style.
* [creator-teardown](creator-teardown/) - Reverse-engineers a short-form creator's video format from their real numbers.
* [cut](cut/) - Cuts raw talking-head footage into a clean jump cut.
* [generate](generate/) - Generates new footage with Higgsfield and puts it on the edit's timeline.
* [improve](improve/) - For the editor's maintainers.
* [logo-pack](logo-pack/) - Builds clean brand-colour logos for every company, app or tool named in a video.
* [motion](motion/) - Builds bespoke motion graphics for an edit, one animated clip per beat (HyperFrames + GSAP), each designed for its line and landing on the spoken word, then lays them on the footage through the style-edit render.
* [motion-design](motion-design/) - >
* [overlays](overlays/) - Works on the visuals of an edit that is already rendered, one beat at a time, without running the whole edit again.
* [product-video](product-video/) - Makes a product launch, feature demo or ad video from a website URL.
* [setup](setup/) - Installs and checks everything ai-editor needs on Mac, Windows or Linux (Python, ffmpeg, Node, git, the Python packages, the free transcription model and the Remotion renderer): on a first run it opens the editor's window first, then installs in the background.
* [skill-improver](skill-improver/) - Turns the feedback on a finished video into lasting rules in the style or skill that made it.
* [skill-maker](skill-maker/) - Helps the user make their own Claude Code skill for editing videos, step by step.
* [start](start/) - The front door of ai-editor.
* [style-edit](style-edit/) - Turns an approved cut into the finished video in a creator's measured style.
* [taste](taste/) - Remembers how the user likes their videos edited, so they never give the same correction twice.
* [update](update/) - Updates ai-editor to its newest version with git.
